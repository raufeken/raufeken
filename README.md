## Featured Projects

### Yaşlı Destek ve Akıllı İlaç Takip Sistemi

Flutter and Firebase-based elderly medication tracking application with OCR-assisted medicine entry, local reminders, stock tracking and caregiver monitoring.

**Technologies:** Flutter, Dart, Firebase, Firestore, FCM, OCR, ML Kit

### YOLO Air Defense Object Detection

YOLO11-based computer vision project for detecting air-defense related objects such as UAVs, missiles, helicopters and fighter aircraft using image, video and webcam inference.

**Technologies:** Python, YOLO11, OpenCV, Machine Learning, Computer Vision

Repository: [YOLO-Air-Defense-Object-Detection](https://github.com/raufeken/YOLO-Air-Defense-Object-Detection)

---

### Graph Algorithm Visualizer

Interactive web-based visualization project for fundamental graph algorithms including Dijkstra, Bellman-Ford, Prim and Kruskal algorithms.

**Technologies:** JavaScript, HTML, CSS, Canvas API

Repository: [graph-algorithm-visualizer](https://github.com/raufeken/graph-algorithm-visualizer)

Live Demo: [Open Demo](https://raufeken.github.io/graph-algorithm-visualizer/)

---

### Compression Algorithms Visualizer

Web-based visualization project for Huffman Coding and LZW compression algorithms, including frequency analysis, encoding process and step-by-step algorithm flow.

**Technologies:** JavaScript, HTML, CSS

Repository: [compression-algorithms-visualizer](https://github.com/raufeken/compression-algorithms-visualizer)

Live Demo: [Open Demo](https://raufeken.github.io/compression-algorithms-visualizer/)

---

### CYK Parser with Tkinter

Python/Tkinter desktop application that analyzes input strings using the CYK algorithm and validates grammars written in Chomsky Normal Form.

**Technologies:** Python, Tkinter, CYK Algorithm, Automata Theory, Formal Languages

Repository: [cyk-parser-tkinter](https://github.com/raufeken/cyk-parser-tkinter)
